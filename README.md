# Contact Book Management System

A Python-based Contact Book Management System that allows users to create, view, update, and delete contact information using JSON file handling.

##  Project Objective

The main objective of this project is to develop a simple and user-friendly contact management system using Python. It helps users manage contact details such as names, phone numbers, and email addresses efficiently.

##  Technologies Used

-  **Programming Language:** Python
-  **Modules:** OS, JSON
-  **Platform:** Jupyter Notebook
-  **Data Storage:** JSON File Handling

##  Features

-  **Create Contact:** Add new contact details.
-  **View Contacts:** Display all saved contacts.
-  **Update Contact:** Modify existing contact information.
-  **Delete Contact:** Remove unwanted contacts.
-  **Save Contacts:** Store contact details in a file.
-  **Load Contacts:** Retrieve previously saved contact details.
-  **Menu-Driven Interface:** Navigate through different operations using menu options.

##  Installation & Setup

1. Install Python on your system.
2. Install Jupyter Notebook.
3. Clone or download this repository.
4. Open the project notebook in Jupyter Notebook.

##  How to Run

1. Open `contact_book_project.ipynb`.
2. Execute all notebook cells in order.
3. Run the menu function.
4. Select an option from the menu.
5. Enter the required contact details.
6. Manage your contacts using Create, View, Update, and Delete operations.

## Available Menu Options

| Option | Operation      |
| :----: | -------------- |
|    1   | Create Contact |
|    2   | View Contact   |
|    3   | Update Contact |
|    4   | Delete Contact |
|    5   | Exit           |
